# SimPaTor Kaltim — Info Pajak Kendaraan Bermotor

**SimPaTor (Sistem Informasi Pajak Kendaraan Bermotor)** merupakan halaman layanan informasi pajak kendaraan bermotor untuk **Provinsi Kalimantan Timur**.

Halaman ini memungkinkan pengguna untuk melakukan pengecekan informasi kendaraan dan kewajiban pajak berdasarkan **Nomor Polisi**.

## 🔎 Informasi Pajak Kendaraan Bermotor

Pada halaman SimPaTor, pengguna dapat memasukkan nomor polisi kendaraan untuk mendapatkan informasi terkait kendaraan.

Halaman:

[SimPaTor — Info Pajak Kendaraan Bermotor](https://simpator-kaltim.vercel.app)

## 📋 Data Kendaraan

Informasi kendaraan yang tersedia pada halaman meliputi:

| Data | Keterangan |
|---|---|
| **Nomor Polisi** | Nomor registrasi kendaraan |
| **Nama Pemilik** | Nama pemilik kendaraan |
| **Alamat Pemilik** | Alamat pemilik kendaraan |
| **Merek Kendaraan** | Merek kendaraan |
| **Tipe / Model Kendaraan** | Tipe atau model kendaraan |
| **Tahun Rakitan** | Tahun kendaraan dirakit |
| **Kepemilikan Kendaraan ke-** | Urutan kepemilikan kendaraan |
| **Nomor Rangka** | Nomor rangka kendaraan |
| **Nomor Mesin** | Nomor mesin kendaraan |

## 💰 Informasi Pajak dan Pembayaran

Selain data kendaraan, halaman juga menyediakan informasi mengenai kewajiban pembayaran kendaraan, antara lain:

| Informasi | Keterangan |
|---|---|
| **Masa Pajak** | Periode masa pajak kendaraan |
| **Masa Berlaku STNK** | Masa berlaku STNK |
| **Biaya Pokok PKB** | Pokok Pajak Kendaraan Bermotor |
| **Biaya Denda PKB** | Denda Pajak Kendaraan Bermotor |
| **Biaya Pokok SWDKLLJ** | Pokok SWDKLLJ |
| **Biaya Denda SWDKLLJ** | Denda SWDKLLJ |
| **PNBP STNK** | Penerimaan Negara Bukan Pajak untuk STNK |
| **PNBP Plat** | Penerimaan Negara Bukan Pajak untuk plat/TNKB |
| **Total Bayar** | Total biaya pembayaran |

## 🧾 Cara Menggunakan

1. Buka halaman **Info Pajak Kendaraan Bermotor SimPaTor**.
2. Masukkan **Nomor Polisi** kendaraan pada kolom yang tersedia.
3. Ikuti proses yang ditampilkan pada halaman.
4. Informasi kendaraan dan rincian pajak akan ditampilkan apabila data tersedia.
5. Periksa **Total Bayar** untuk mengetahui jumlah pembayaran yang tercantum.

## 🏛️ Wilayah Layanan

Layanan ini ditujukan untuk kendaraan yang terdaftar di wilayah **Provinsi Kalimantan Timur**.

SimPaTor juga merupakan bagian dari layanan informasi yang berkaitan dengan **Bapenda Provinsi Kalimantan Timur**.

## ⚠️ Catatan

Informasi yang ditampilkan pada halaman mengikuti data yang tersedia pada sistem SimPaTor pada saat pengecekan dilakukan.

Untuk keperluan pembayaran, administrasi kendaraan, atau konfirmasi data, pengguna sebaiknya mengikuti informasi dan prosedur resmi yang berlaku.
